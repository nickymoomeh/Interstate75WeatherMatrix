Interstate 75 Weather Matrix

Browser emulator for the standalone 64×64 Open-Meteo edition.

Enter a location or latitude/longitude, then press Start.
How it works

The page calls Open-Meteo directly from your browser. Weather refreshes every 10 minutes; animation runs locally. Settings are saved only in your browser using localStorage. No Wi-Fi password or API key is required.

The 12-hour option deliberately omits AM/PM to preserve the real matrix layout. Three-digit Fahrenheit MIN/MAX values drop the decimal, matching the firmware.
